# Xianxia v0.1.2 — Interface & Quality of Life Update

Original Workshop update: July 21, 2026.

This update improves the Cultivator's Manual, Qi interface, visual customization, and breakthrough preparation.

## Qi Interface

- Added a Breakthrough Readiness panel when hovering over the Qi bar.
- Added next-Stage requirements, remaining QiEXP, stat bonuses, and upcoming Realm abilities.
- Added Heavenly Tribulation estimates, including lightning count and Qi Protection cost.
- Added automatic text wrapping to the information panel.

## Cultivator's Manual

- Added mouse-wheel scrolling and a draggable scrollbar.
- Added a return-to-top button and an indicator for content below.
- The Manual now remembers the last opened page.
- Fixed text overlapping navigation buttons.
- Scrolling the Manual no longer changes the selected inventory slot.

## Configuration and Improvements

- Added configurable Qi bar positioning and scale.
- Added options for Qi Concentration visibility and visual-effect intensity.
- Updated the English and Italian Manual and interface text.
- Reduced the packaged mod size by excluding development and temporary files.
- Added various interface and presentation improvements.

Install Xianxia from the [tModLoader Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3768052356).
