# Xianxia v0.1.3 — Spirit Beasts

Original Workshop update: July 22, 2026.

Spirit Beasts have entered Terraria. Their strength, cultivation Stage, and rewards increase as players travel farther from the world spawn.

## Spirit Beasts

- Added the Spirit Hare, Jade Horn Deer, Flame-Tailed Fox, and Thunderclaw Tiger.
- Added custom animated sprites and readable Realm-colored nameplates.
- Added distance-based Realm and Stage progression using the shared world spawn.
- Added configurable spawning in forests, snow biomes, jungles, and beaches.

## Materials and Alchemy

- Added Spirit Fur, Spirit Beast Blood, Jade Antler, Flame Essence, and Thunder Essence.
- Added Beast Cores for multiple cultivation Realms.
- Added Spirit Beast pills and unique textures for the new materials.

## Improvements

- Added Spirit Beast summoning and spawn-diagnostic debug commands.
- Fixed Qi Flight being interrupted when opening chat.
- Updated the English and Italian Cultivator's Manual.
- Improved Spirit Beast label readability.

Install Xianxia from the [tModLoader Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3768052356).
