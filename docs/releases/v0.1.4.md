# Xianxia v0.1.4 — Alchemy Expansion

Released July 22, 2026.

This update expands alchemy into a complete cultivation path and introduces Simplified Chinese localization.

## Alchemy Path

- Added five Alchemy Tiers matching Mortal through Nascent Soul.
- Added Low, Middle, and High Stages within each Tier.
- Added Alchemy Mastery progression.
- Better Cauldrons and higher Mastery improve bonus yield and reduce impurities.
- Added Pill Saturation, which prevents unlimited pill stacking and gradually reduces effectiveness.

## Herbs and Cauldrons

- Added Spirit Grass, Fire Lotus, Moon Dew Flower, and Ironroot.
- Added renewable seeds so the new herbs can be obtained in existing worlds.
- Added Spirit Jade and Profound Alchemy Cauldrons as refining upgrades.

## Pills and Progression

- Added new Qi recovery, saturation-cleansing, breakthrough, resistance, and utility pills.
- Added Realm-scaling effects and advanced recipes using spiritual resources and Spirit Beast materials.
- Expanded the Cultivator's Manual with the new alchemy progression and recipes.

## Localization

- Added Simplified Chinese localization.
- Updated English and Italian text for the expanded content.
