# Xianxia v0.1.5 — Equipment and Manual Refinement

Released July 23, 2026.

This update improves early-game presentation, redraws cultivation equipment, and makes the Cultivator's Manual easier to browse.

## Novice Disciple Attire

- Added a craftable Novice Disciple Headband, Robe, and Trousers.
- The full set provides modest early-game defense, damage, movement, critical chance, and meditation bonuses.
- Every piece supports Terraria dyes and can also be used in vanity slots.

## Spirit Jade Armor Redesign

- Replaced the oversized crown with a slim jade circlet.
- Redesigned the robe and leggings with a cleaner Xianxia silhouette.
- Rebuilt item icons directly at native resolution.
- Updated equipment sheets without resizing source artwork.

## Cultivator's Manual

- Consolidated all crafting recipes into a single scrollable catalogue.
- Added category headers for attire, equipment, techniques, cauldrons, and pills.
- Added Alchemy rank requirements beneath pill names.
- Added all Novice Disciple recipes and both Spirit Vein Compass variants.

## Configuration and Localization

- Added a client option to hide Spirit Beast nameplates.
- Updated English, Italian, and Simplified Chinese text for the new content.

Install Xianxia from the [tModLoader Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3768052356).
