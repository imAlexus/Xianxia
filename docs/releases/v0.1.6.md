# Xianxia v0.1.6 — Sects and Permanent Formations

Released July 26, 2026.

This update introduces the Verdant Cloud Sect, persistent Array Formations, Relay specialization, and pill quality.

## Verdant Cloud Sect

- Added Elder Jian and four Sect ranks.
- Added missions for hunting, deliveries, Alchemy, Spirit Veins, and Tribulations.
- Added Sect Contribution Tokens, lifetime contribution, a Sect menu, and a dedicated shop.
- Added Sword Intent, Spirit Sword Rain, and Sect Protection Formation manuals.
- Expanded Sect Protection Formation with shared Qi, allied support, Spirit Stones, Spirit Veins, scaling integrity, and longer duration.

## Permanent Array Formations

- Added the five-Tier Array Formation Path with Low, Middle, and High Stages.
- Added persistent Formation Cores with ownership, stored Qi, integrity, access controls, resource bars, and a dedicated UI.
- Added Protection, Spirit Gathering, Suppression, and Restoration modes.
- Protection barriers block external hostile projectiles, repel enemies, prevent hostile natural spawning, and intercept Heavenly Tribulations.
- Added automatic integrity repair using network Qi.
- Added manual structural upgrades requiring Path mastery, materials, and Beast Cores.
- Added automatic Spirit Vein power with generation capped by local Qi Concentration.

## Formation Relay Flags

- Added 40-block Relay territories for extending Formation networks beyond the Core's 80-block limit.
- Relays share Core resources, consume upkeep, display world bars, and can channel distant Spirit Veins.
- Added a Relay status and specialization UI.
- Normal Extension applies every enabled Core mode at standard strength.
- Protection, Gathering, Suppression, and Restoration specializations provide stronger local effects.
- Relay state and choices are saved and synchronized in multiplayer.

## Alchemy and Presentation

- Added persistent pill quality: Impure, Common, Refined, Earth Grade, and Heaven Grade.
- Quality changes effect strength, duration, cleansing power, and Saturation.
- Better mastery and Cauldrons improve quality rolls; impurities can produce Pill Dregs.
- Improved spiritual herb growth-stage visibility.
- Updated the Cultivator's Manual and all three localizations.
