# Xianxia v0.1.0 — Initial Release

Original Workshop release: July 19, 2026.

Xianxia begins its cultivation journey in Terraria.

## Highlights

- Five cultivation Realms: Mortal, Qi Gathering, Foundation Establishment, Core Formation, and Nascent Soul.
- Nine Stages per Realm, for a total of 45 cultivation levels.
- Separate Qi and QiEXP progression systems.
- Meditation, breakthroughs, passive abilities, and spiritual techniques.
- Heavenly Tribulations for higher-Realm breakthroughs.
- Spirit Stone mines and Qi Concentration.
- Spiritual equipment, basic alchemy, and the Cultivator's Manual.
- English and Italian localization.

Install Xianxia from the [tModLoader Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3768052356).
