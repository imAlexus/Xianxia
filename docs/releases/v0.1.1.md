# Xianxia v0.1.1 — Cultivation Balance Update

Original Workshop update: July 19, 2026.

This update improves cultivation balance, spiritual techniques, and survivability mechanics.

## Changes

- Greatly increased Heavenly Tribulation difficulty.
- Tribulation lightning now consumes a percentage of maximum Qi.
- Part of Tribulation damage now penetrates Qi Protection.
- Improved Qi Protection against lava, debuffs, and drowning.
- Fixed meditation while Qi-consuming techniques are active.
- Expanded Qi Concentration levels from 0 to 10.
- Improved Spirit Stone Mine cultivation bonuses.
- Added the Night Vision technique for Foundation Establishment.
- Improved Spiritual Pressure visual effects.
- Added and improved Xianxia debug commands.
- Updated the Cultivator's Manual.
- Added various balance changes and bug fixes.

Install Xianxia from the [tModLoader Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3768052356).
